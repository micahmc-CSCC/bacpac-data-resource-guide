## About BACPAC

The Back Pain Consortium (BACPAC) was a component of the NIH Helping to End Addiction Long-term® (HEAL) Initiative. BACPAC brought together researchers, clinicians, patients, and data scientists to improve the understanding, prevention, and treatment of chronic low back pain through coordinated clinical studies, data collection, and data sharing.

As BACPAC activities conclude, this repository serves as a long-term reference resource for investigators, data users, and the broader research community. It preserves guidance and documentation that support the discovery, interpretation, and reuse of BACPAC data resources.

The platform serves as the central discovery resource for HEAL-funded studies and datasets and should be considered the authoritative source for current repository locations and data access information.

### BACPAC Data Validator

Researchers preparing or reviewing BACPAC-formatted datasets may find the BACPAC validation tool useful.

**Repository:** https://github.com/Vincent-Toups/bacpac_val

The validator supports assessment of dataset structure and conformance with BACPAC data specifications and can assist with quality control and standardization activities.

## The BEST Trial: Biomarkers for Evaluating Spine Treatments

The BEST Trial was the primary collaborative clinical trial conducted within the BACPAC Research Program. The study was designed to inform precision medicine approaches for chronic low back pain by evaluating how patient characteristics and treatment response can be used to optimize treatment selection.

**ClinicalTrials.gov:** https://clinicaltrials.gov/study/NCT05396014

**Design and rationale publication:** https://doi.org/10.1093/pm/pnaf032

Links to BEST Trial repositories, documentation, publications, and data resources will be added as they become publicly available.

**Planned resources:**

- Study documentation
- Dataset descriptions
- Analysis resources and tools
